######################################################################
######################### FLOW TRANSLATIONS ##########################
######################################################################
#
# Every text Flow shows, in English (en) and German (de).
#
# How an entry reads:
#
#   settings.general.equalizeVolume.label      <- the key: where the text is used (never translate it)
#     en: Equalize volume                      <- the English text
#     de: ...                                  <- the German text, added under the en line
#
# Rules:
#   - A missing de line is fine: Flow then shows the English text.
#   - {name} is filled in by Flow (a song, a number, a playlist...). Keep it exactly as it is;
#     it may move anywhere in the sentence.
#   - en.one / en.other: the text for exactly 1 and for any other number. German gets
#     de.one / de.other the same way.
#   - \n starts a new line.
#   - Lines starting with # are notes and are not shown in Flow.
#   - German uses "du". Song stays Song, Playlist stays Playlist.
#
